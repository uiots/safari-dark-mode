Safari Dark Mode 0.1.0

One permission, then the lights go down.

Safari controls whether extensions may read and change websites. Safari Dark Mode needs access to ordinary HTTP and HTTPS pages so it can detect native dark themes and darken light ones.

  1. Open Safari → Settings → Websites → Extensions.
  2. Select Safari Dark Mode.
  3. Choose Allow for All Websites.
Your settings stay in Safari’s local extension storage. This extension contains no analytics, telemetry, or remote code.
